# Горец — горное селение

Phaser 3 + TypeScript + Vite. Играбельный визуальный прототип первого спуска.

## Запуск

Node.js 22.12+ или 24 LTS. В терминале WebStorm:

```bash
yarn install
yarn dev
```

Открой адрес из терминала (обычно http://127.0.0.1:5173).
Остановка сервера: Ctrl+C. Не открывай index.html двойным кликом.

## Управление

- A/D или стрелки — движение.
- Пробел, W или стрелка вверх — прыжок; короткое нажатие даёт низкий прыжок.
- R — перезапуск, в том числе после финиша.
- После падения уровень начинается заново.
- Цель: флаг в нижнем селении, справа.

## Проба иллюстрированных ассетов

Ветка `codex/illustrated-assets` подключает настоящие растровые иллюстрации
из `public/assets/illustrated/`: окружение, героя, фон и грунт (WebP, около 1 МБ
в сумме). Старые процедурные генераторы сохранены в исходниках, но не вызываются.

Дом, дерево, кусты, камни и реквизит извлекаются из атласа. Кадры героя
нормализуются по размеру и линии ног: шесть беговых поз, ожидание, прыжок.
Это первый вариант анимации, его ещё нужно оценить при реальном запуске.
Canvas используется для подготовки текстур и укладки изображения грунта по
существующим склонам; сам рисунок берётся из файлов, а не строится из примитивов.

Фоновая иллюстрация рисуется отдельной сценой; старые дальние дома убраны,
чтобы не смешивать качество и не создавать зависающие объекты. Вода остаётся
анимированной. Маршрут и управление сохранены, камера остаётся отдалённой.

Отрисовка учитывает devicePixelRatio и размер окна при запуске (до 2×),
не меняя размеров мира и интерфейса. На Retina холст становится 2560×1440
при прежнем логическом размере 1280×720. Текст тоже рисуется с нужной плотностью.

Это пробный участок для оценки художественного направления, не финальный арт
всей игры. Ассеты созданы генерацией изображений и включены в репозиторий;
новых npm-зависимостей и внешних URL загрузки нет.

## Бесшовная анимация воды

`public/assets/illustrated/water-sheet.webp` остаётся исходной иллюстрацией.
Для анимации используется один полный период из первой ячейки: остальные
сгенерированные позы не образовывали согласованного цикла.

`waterLoop.ts` соединяет края периода и собирает 24 равномерные фазы
в атлас 6×4 при загрузке. Интерполяция выполняется с premultiplied alpha,
чтобы прозрачный воздух не создавал белые швы. Произвольных сдвигов разных
картинок и разрезания волн посередине больше нет.

Переключение — каждые 50 мс (20 кадров/с), полный цикл — 1,2 секунды.
Все кадры имеют одинаковый уровень воды и палитру. Поверхность ниже уступов,
края скрыты землёй, падение в воду перезапускает уровень. Атлас создаётся
один раз, во время игры меняется только номер кадра.

`yarn check:water` проверяет цикл, повторение периодов, прозрачность,
горизонтальные края и переход последнего кадра к первому.

## Проверки

```bash
yarn check:terrain
yarn build
yarn preview
```

`check:terrain` выполняет реальный метод столкновения героя с рельефом:
проверяет спуск, подъём, падение в разрыв, прыжок через него, приземление
и отсутствие телепортации на поверхность снизу. Это проверка геометрии,
а не полный браузерный тест ввода или рендера.

`dist/` — готовая браузерная сборка.

## Структура

- `src/game/config.ts` — окно, физика, сцены.
- `src/game/scenes/BootScene.ts` — подготовка пиксельных текстур и героя.
- `src/game/scenes/Level01Scene.ts` — планы окружения, рельеф, камера, интерфейс.
- `src/game/entities/Player.ts` — движение, прыжок и столкновения со склонами.
- `src/game/art/playerTexture.ts` — пиксельный рисунок героя и позы.
- `src/game/levels/level01.ts` — точки рельефа, разрыв, дома и финиш.
- `public/assets/environment/` — три SVG-варианта дагестанских домов.

Для склонов используется одна и та же линия в отрисовке и в физике:
`groundY(x)`. Ноги героя разрешаются относительно неё после каждого шага
Arcade Physics; это позволяет ходить по склону без лестницы прямоугольных коллайдеров.
