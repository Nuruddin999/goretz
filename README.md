# Горец — горное селение

Phaser 3 + TypeScript + Vite. Играбельный визуальный прототип первого спуска.

## Запуск

Node.js 22.12+ или 24 LTS. В терминале WebStorm:

```bash
yarn install
yarn dev
```

Открой адрес из терминала (обычно http://127.0.0.1:5173).
Остановка сервера: Ctrl+C. Не открывай index.html двойным кликом.

## Управление

- A/D или стрелки — движение.
- Пробел, W или стрелка вверх — прыжок; короткое нажатие даёт низкий прыжок.
- R — перезапуск, в том числе после финиша.
- После падения уровень начинается заново.
- Цель: флаг в нижнем селении, справа.

## Геометрический вариант для сравнения

Ветка `codex/geometric-village` — отдельная проба гладкой геометрической графики
в направлении Geometry Dash: контрастные плоскости, тонкие светлые грани,
глубокие сине-зелёные тени и подсвеченные окна. Дагестанские дома сохраняют
плоские крыши, арки и деревянные галереи. Это оригинальные рисунки, без чужих ассетов.

Камера отдалена до 70%: видно больше маршрута, герой и дома заметно меньше.
Интерфейс рисуется отдельной камерой и сохраняет обычный размер. Пиксельный
режим и CSS pixelated отключены, текстуры рисуются в высоком разрешении со сглаживанием.

Окружение: `src/game/art/geometricEnvironment.ts`, герой:
`src/game/art/playerTexture.ts`. Текстуры создаются один раз при старте;
новых зависимостей и сетевых ассетов нет. Предыдущие SVG и пиксельный генератор
сохранены для сравнения, но не загружаются в этой версии.

Это визуальная проба: движение, прыжок и маршрут сохранены; бой, враги,
автобег и управление Geometry Dash не добавлены.

## Проверки

```bash
yarn check:terrain
yarn build
yarn preview
```

`check:terrain` выполняет реальный метод столкновения героя с рельефом:
проверяет спуск, подъём, падение в разрыв, прыжок через него, приземление
и отсутствие телепортации на поверхность снизу. Это проверка геометрии,
а не полный браузерный тест ввода или рендера.

`dist/` — готовая браузерная сборка.

## Структура

- `src/game/config.ts` — окно, физика, сцены.
- `src/game/scenes/BootScene.ts` — подготовка пиксельных текстур и героя.
- `src/game/scenes/Level01Scene.ts` — планы окружения, рельеф, камера, интерфейс.
- `src/game/entities/Player.ts` — движение, прыжок и столкновения со склонами.
- `src/game/art/playerTexture.ts` — пиксельный рисунок героя и позы.
- `src/game/levels/level01.ts` — точки рельефа, разрыв, дома и финиш.
- `public/assets/environment/` — три SVG-варианта дагестанских домов.

Для склонов используется одна и та же линия в отрисовке и в физике:
`groundY(x)`. Ноги героя разрешаются относительно неё после каждого шага
Arcade Physics; это позволяет ходить по склону без лестницы прямоугольных коллайдеров.
