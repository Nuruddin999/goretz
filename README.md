# Горец — прототип 0.1

Phaser 3 + TypeScript + Vite. Первый черновой участок «Горная тропа».
Графика процедурная, временная; внешние изображения и звук не требуются.

## Запуск на Mac

Нужен Node.js 22.12+ (рекомендуется 24 LTS).
Открой папку проекта в WebStorm, затем в терминале:

```bash
npm ci
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).
Для остановки: Ctrl+C. Не открывай index.html двойным кликом.

## Управление

- A/D или стрелки — движение.
- Пробел, W или стрелка вверх — прыжок; короткое нажатие даёт низкий прыжок.
- R — перезапуск. После падения уровень начинается заново.
- Цель: флаг справа, в конце спуска.

## Проверка и сборка

```bash
npm run build
npm run preview
```

`dist/` — готовая браузерная сборка. В архиве исходников зависимости и dist не включены.
Мобильное управление, бой, враги, анимации и сохранения пока не реализованы.

## Структура

- src/game/config.ts — размеры окна, физика, сцены.
- src/game/scenes/BootScene.ts — временные текстуры, запуск уровня.
- src/game/scenes/Level01Scene.ts — окружение, столкновения, камера, финиш.
- src/game/entities/Player.ts — движение, прыжок, небольшой запас времени у края и буфер прыжка.
- src/game/levels/level01.ts — геометрия и точки уровня.
- public/assets/ — будущие изображения, звук и интерфейс.

Сначала настраиваем движение и геометрию, затем заменяем временную графику.
